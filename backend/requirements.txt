# Нижние границы, а не точные версии — сознательно.
#
# Чек-лист требует фиксировать версии в проде, и это верно. Но фиксировать
# нужно то, что вы РЕАЛЬНО проверили на своём интерпретаторе, а не то, что
# было актуально у автора. Первая версия этого файла была закреплена точно —
# и не установилась вообще ни одним пакетом, потому что окружение собрали на
# Python 3.14, для которого у numpy 2.2 и pydantic 2.10 нет собранных колёс.
# Точная фиксация несуществующей сборки — это не воспроизводимость, это
# гарантированная поломка на другой машине.
#
# Правильный порядок: границы здесь -> установка -> `pip freeze` в lock-файл,
# и уже он идёт в прод:
#
#     pip install -r requirements.txt
#     pip freeze > requirements.lock.txt
#
# Тогда в проде стоит ровно то, что вы проверили, а не то, что угадали.
