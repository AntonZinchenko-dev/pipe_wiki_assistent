# SURVEYD — сервис инклинометрии

## Что делает сервис

SURVEYD хранит инклинометрические съёмки скважин и выдаёт по ним траекторию,
пересчитанную методом минимальной кривизны. Каждая съёмка версионируется:
идентификатор версии — `survey_version_id`, и все расчётные результаты в
других сервисах ссылаются именно на него.

Съёмка — это набор станций с тремя величинами на каждой: глубина по стволу,
зенитный угол, азимут. Всё остальное (координаты в пространстве, DLS,
проекции) считается из этих трёх и не хранится.

## Почему сервис не выставлен наружу

SURVEYD доступен только внутри контура: другим сервисам — по внутренней сети,
внешним потребителям — никак. Причина не техническая, а регуляторная. Съёмка
однозначно привязывает скважину к географическим координатам, а координаты
скважин заказчика относятся к сведениям, которые по договору не покидают
периметр компании. Открыть эндпоинт наружу можно только после согласования с
юридической службой заказчика и подписания отдельного приложения к договору.

Практическое следствие: PIPEPASS не может показать 3D-ствол и профиль DLS на
боевом контуре, хотя данные в системе есть. На демонстрационном контуре эти
экраны работают на сгенерированных фикстурах, и интерфейс прямо сообщает
пользователю, что данные демонстрационные.

Обходить это ограничение выгрузкой съёмок в файлы и раздачей файлов
потребителям запрещено. Ограничение действует на данные, а не на конкретный
транспорт.

## Метод минимальной кривизны

Между двумя соседними станциями траектория считается дугой окружности,
лежащей в плоскости, содержащей оба вектора направления. Приращения координат
на интервале:

```
DL   = arccos( cos(I2−I1) − sin(I1)·sin(I2)·(1 − cos(A2−A1)) )
RF   = (2 / DL) · tan(DL / 2)
ΔN   = (ΔMD / 2) · ( sin(I1)·cos(A1) + sin(I2)·cos(A2) ) · RF
ΔE   = (ΔMD / 2) · ( sin(I1)·sin(A1) + sin(I2)·sin(A2) ) · RF
ΔTVD = (ΔMD / 2) · ( cos(I1) + cos(I2) ) · RF
```

где `I` — зенитный угол, `A` — азимут, `MD` — глубина по стволу, `RF` —
коэффициент отношения. При `DL → 0` коэффициент `RF` стремится к единице, и
формула вырождается в метод усреднённых углов; в коде этот случай обработан
отдельно, чтобы не делить на ноль.

**DLS** (dogleg severity) — интенсивность искривления, приводится к 30 метрам:

```
DLS = DL · (30 / ΔMD)   [градусов на 30 м]
```

## Коды ошибок

| Код       | HTTP | Значение                                              |
| --------- | ---- | ----------------------------------------------------- |
| `SVY-404` | 404  | Съёмка с указанным `survey_version_id` не найдена     |
| `SVY-409` | 409  | Съёмка перезаписана более новой версией               |
| `SVY-422` | 422  | Станции идут не по возрастанию глубины                |
| `SVY-451` | 451  | Запрос из внешнего контура — доступ закрыт регламентом |

Код `SVY-409` — самая частая причина расхождений между сервисами. Он означает,
что расчёт, на который ссылается потребитель, посчитан на съёмке, которую
затем перезаписали. Правильная реакция — перезапросить актуальную версию и
пересчитать, а не повторять исходный запрос.

## Версионирование съёмок

Съёмка никогда не изменяется на месте. Уточнение данных создаёт новую версию,
старая остаётся доступной по своему идентификатору. Это нужно, чтобы расчёт
усталости, сделанный полгода назад, оставался воспроизводимым: результат
всегда можно объяснить, указав, на какой именно съёмке он получен.

Удаление версии съёмки не предусмотрено ни в API, ни в административном
интерфейсе. Единственное исключение — удаление по официальному запросу
заказчика на удаление данных скважины целиком; такая операция выполняется
администратором базы данных вручную и протоколируется.
